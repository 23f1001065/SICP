# Sponser and Influencer Coordination Webplatform


##  About : 
This is my first college Project on Modern Application Development that allow sponsors( any individual or a company who works as a sponsor ) to get advertised  their products/services and influencers to get monetary benefit for advertisement on behalf of those influencers.

This is first web application development project in our IITM BS Data Science program that gave me an complete and overall idea of how web based application works.

## Technology Used:
 As this project introduce me how to develop my first web application so this is developed using basic tech satck. Those are ----
 
 * **HTML** --> Hypper Text Markup Language
 * **CSS** --> Cascade Style sheet
 * **Jinja** --> Template library for showing data inside html 
 * **Sqlit3** --> Filebased and light relational database 
 * **Flask** --> Python language based backend development framwork
 * **Flask-SqlAlchemy** --> Object Relational Mapper for database access related activity


## File and Folder Structure : 
I tried to develop in a modular fashion. There are four folder and three files in root directory. Each folder represent separate development section of the application. They are namely -----

* **Application** 
    
    This folder contains all backend business logic code written in python.
* **Templates**

    This folder contains all the html codes.
* **Static**

    This folder contains only css files.
* **Database**

    This folder has only filebased SqLite3 relational Database file.


Also in this root folder I have **main.py** as the application runner code and **README.md** and **requirements.txt** files.
